# Rehearsal: cyber security assessor

Interviewer: Innovox (rehearsal) · Date: 10 November 2026 · Topic: default script, platform concept and gate review wireframe

**Walk me through the last time you reviewed security evidence.**
I assess whether delivery teams are following Secure by Design and the relevant policies and standards. I read what the team provides and decide whether it shows that risks are found and managed. A lot of what I see is documents asserting things, not evidence of them.

**What took longest? What was redone?**
Working out whether evidence is genuine and current. A screenshot has no date I can rely on. A scan report doesn't tell me which version of the system it ran against.

**What would you need to trust evidence produced by a tool?**
Provenance: which tool, which version, which target, when, with what vulnerability data. Reproducibility: can I re-run it, or have someone independent re-run it? And honest coverage: show me what wasn't assessed, and keep automated checks separate from things a person has claimed.

**Who decides whether a tool like this is used, and how is it bought?**
I don't buy anything. But if I don't trust the evidence it produces, it's worthless to the team, so in practice I decide whether it's useful.

**What would make you stop using it?**
Evidence generated by the supplier's own tool is self-marking. If I can't verify it independently, I'll treat it like any other supplier claim. And if an LLM decided something passed, I'd want to know exactly how that decision was checked.

**Concept and gate review wireframe: hashed evidence, coverage by standard, LLM findings shown with citations and calibration, a named approver.**
The evidence hash and the coverage bars are the most useful things on that screen. Showing "24 of 63, manual" for Def Stan 05-138 is honest; I'd trust it more for that. The LLM finding with a confidence score and citations is acceptable as advice, but I'd want it impossible for an LLM verdict alone to pass a gate. What would really change things is if I could re-run the assessment myself from the recorded versions, without the supplier's help.

## Objections raised
- Supplier-generated evidence is self-marking
- I need to re-run it independently
- LLM judgements must never pass a gate alone

## Assumptions this rehearsal suggests
- Assessors would trust platform evidence more if they can reproduce it themselves.
- Explicitly showing manual and unassessed coverage increases assessor trust.
- An assessor-side "verify and re-run" capability could be a product feature in its own right.
- Assessors accept LLM findings as advisory if they are cited and calibrated.

## Questions to ask real people
- What makes a piece of evidence acceptable to you today, and what makes you reject it?
- Would you use a tool to independently re-run a supplier's assessment if it were provided?
- How do you currently treat findings that come from automated tools?
